CSS Attribute Selectors

1. [attribute]

[data-required] { border-left: 3px solid red; }

This has data-required

2. [attribute="value"]

[type="submit"] { background: #2ecc71; color: white; }

3. [attribute~="value"]

[class~="hl"] { background: #f1c40f; }
Has the hl class
Doesn't have hl
No exact match

4. [attribute|="value"]

[lang|="en"] { border-bottom: 2px dotted blue; }
English
American English
British English
French (not selected)

5. [attribute^="value"]

[href^="https"] { color: green; font-weight: bold; } Secure HTTPS Link Regular HTTP Link Another HTTPS Link

6. [attribute$="value"]

[src$=".jpg"] { border: 3px solid orange; }

7. [attribute*="value"]

[title*="important"] { color: red; font-weight: bold; }
This is important
Regular notice
Important alert
